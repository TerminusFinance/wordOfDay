# WordOfDay — Telegram Mini App (TON)

A Telegram Mini App game on TON: daily phrases/predictions, tasks, referrals and an airdrop, with NFT-based perks.

## Structure
- `backEnd/` — Node/TypeScript API (auth, phrases, tasks, premium, TON/NFT checks, Telegram bot)
- `front/` — React + Vite Mini App UI (predictions, tasks, referrals, profile, airdrop)

## Stack
TypeScript · React · Vite · TON · Telegram Mini Apps · i18n (EN/RU)
