# 📊 Диагностический отчет проекта "Word of Day"

## 📋 Обзор проекта

**Word of Day** - это полнофункциональное приложение для Telegram с поддержкой TON блокчейна, разработанное компанией TerminusFinance. Проект представляет собой мини-приложение (mini-app) для получения мотивационных фраз дня с элементами геймификации.

### 🏗️ Архитектура проекта

```
wordOfDay/
├── front/          # Frontend (React + TypeScript + Vite)
├── backEnd/        # Backend (Node.js + Express + TypeScript)
├── .github/        # GitHub workflows и конфигурация
└── .gitattributes  # Git конфигурация
```

## 🔍 Детальный анализ

### 📱 Frontend (React приложение)

**Технологический стек:**
- **React 18.3.1** с TypeScript
- **Vite** для сборки проекта
- **Telegram Mini Apps SDK** для интеграции с Telegram
- **TON Connect** для работы с блокчейном TON
- **i18next** для интернационализации
- **React Router** для навигации

**Функциональность:**
- Экраны: Загрузка, Стартовый, Прогнозы, AirDrop, Рефералы, Задания, Профиль
- Интеграция с Telegram Web App API
- Поддержка мультиязычности (русский/английский)
- Интеграция с TON кошельками

### 🔧 Backend (Node.js сервер)

**Технологический стек:**
- **Express.js** веб-сервер
- **TypeScript** для типизации
- **TypeORM** для работы с базой данных
- **MySQL** база данных
- **Redis** для кеширования
- **OpenAI API** для генерации контента
- **Telegram Bot API** для бота
- **TON blockchain** интеграция

**Функциональность:**
- REST API для мини-приложения
- Telegram бот с inline клавиатурой
- Система пользователей и рефералов
- Система заданий и наград
- Интеграция с платежными системами
- Генерация мотивационных фраз через OpenAI

**Статус сборки:** ✅ **УСПЕШНО**

**База данных:**
- 8 таблиц: users, users_data, UserPhrases, user_invitations, tasks, userTasks, acquisitions, premium
- Автоматическая миграция схемы при запуске
